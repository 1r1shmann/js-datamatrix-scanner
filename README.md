# DataMatrix Scanner (Prototype)

Простой прототип браузерного сканера DataMatrix-кодов, реализованный на JavaScript с использованием библиотеки `html5-qrcode`.

## 📌 Описание

Проект демонстрирует базовую работу сканирования DataMatrix-кодов через камеру устройства прямо в браузере без серверной части.

Поддерживается:
- сканирование через заднюю камеру устройства
- распознавание DataMatrix кодов
- вывод результата на экран
- вибро-отклик при успешном сканировании

## 🚀 Запуск

1. Скачайте или клонируйте репозиторий
2. Убедитесь, что рядом лежит файл: html5-qrcode.min.js
3. 3. Откройте `index.html` в браузере
4. Нажмите кнопку **"Старт"**
5. Разрешите доступ к камере

## 🧪 Использование

После запуска:
- наведите камеру на DataMatrix-код
- результат появится в блоке **"Результат"**
- устройство слегка вибрирует при успешном сканировании
